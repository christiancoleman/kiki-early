## External software

The historical scripts and source use separately supplied software:

- QEMU user-mode emulation and an AArch64 GNU/Linux toolchain.
- Linux system libraries and graphics interfaces.
- Mesa for EGL/OpenGL ES; the overlay script downloads external Debian packages.
- FFmpeg tools and libraries, with PyAV for host decoding.
- Python, NumPy, Pillow, PyOpenGL, and Tk for host tools and presentation.
